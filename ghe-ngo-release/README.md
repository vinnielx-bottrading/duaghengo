# Ghe Ngo – Nhịp Chèo Đồng Lòng

Game 2D tái hiện lễ hội đua ghe Ngo của đồng bào Khmer Nam Bộ.
Người chơi giữ nhịp chèo theo tiếng còi/chiêng/chuông qua 5 màn: Tập chèo,
Hạ thủy ghe, Vòng loại, Đêm rằm tháng Mười (cúng trăng – thả đèn nước), Chung kết.
Sau mỗi màn thắng sẽ mở một thẻ văn hóa kèm câu hỏi trắc nghiệm.

**Lưu ý:** Nội dung văn hóa trong game hiện là bản nháp, chưa qua kiểm duyệt
bởi chuyên gia/cộng đồng Khmer. Cần kiểm tra lại trước khi phát hành chính thức.

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt, hoặc bật GitHub Pages cho repo
này (Settings → Pages → Deploy from branch → root) để có link chơi online.

## Điều khiển

- Chạm màn hình / click chuột, hoặc phím Space / Enter / J / F: chèo theo nhịp
- Esc hoặc P: tạm dừng
